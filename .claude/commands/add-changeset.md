コード変更に対応するチェンジセットを追加します。

1. `git diff --stat HEAD` を実行して、変更されたファイルを確認してください。
2. 変更内容に基づき、影響を受けるパッケージと適切なバージョンアップ種別を判断してください。
   - `patch`: バグ修正・内部改善
   - `minor`: 後方互換性のある新機能追加
   - `major`: 破壊的変更（既存の公開 API の変更・削除）
3. `pnpm changeset` を実行して、対話形式でチェンジセットを追加してください。
4. 追加したチェンジセットファイルを確認し、変更の説明が正確かどうかをチェックしてください。

詳細なリリースフローは `.claude/docs/release.md` を参照してください。
